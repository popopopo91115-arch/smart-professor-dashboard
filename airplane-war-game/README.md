# ⚔️ حرب الطيارات - Sky Warriors ⚔️

لعبة حرب طيارات ثنائية الأبعاد مبنية باستخدام HTML5 Canvas و JavaScript بجرافيكس متقدم ونظام بوسز (Boss System).

## 🎮 المميزات

### جرافيكس متقدم
- خلفية فضائية متحركة مع نجوم ونيبولا (Nebula)
- تأثيرات جسيمات (Particles) متقدمة للانفجارات
- تأثيرات إضاءة وتوهج (Glow effects)
- رسومات مفصلة للطائرات والأعداء
- تأثير اهتزاز الشاشة عند الانفجارات

### نظام البوسز (Boss System)
- **المرحلة 1:** الصقر الأحمر (Red Hawk) - هجمات منتشرة ومطر رصاص
- **المرحلة 2:** العقرب الذهبي (Golden Scorpion) - هجمات حلزونية وليزر
- **المرحلة 3:** التنين الأخضر (Green Dragon) - موجات وهجمات مركبة
- **المرحلة 4:** فينيكس الظلام (Dark Phoenix) - جميع أنماط الهجوم
- **المرحلة 5+:** أوميغا المدمر (Omega Destroyer) - صعوبة متزايدة

كل بوس يمتلك:
- 3 مراحل قوة (Phases) تتغير حسب الصحة المتبقية
- أنماط هجوم متعددة (Spread, Spiral, Burst, Wave, Laser, Rain)
- شريط صحة مرئي
- تأثيرات موت سينمائية

### نظام الأعداء
- **Basic:** عدو أساسي بسيط
- **Fast:** عدو سريع بحركة متعرجة
- **Tank:** عدو ثقيل بصحة عالية
- **Shooter:** عدو يصوب نحو اللاعب
- **Elite:** عدو نخبوي بهجمات منتشرة

### نظام التحسينات (Power-ups)
- 🟢 **W** - تحسين السلاح (5 مستويات)
- 🔴 **+** - حياة إضافية
- 🔵 **S** - درع حماية مؤقت
- 🟡 **Z** - شحن السلاح الخاص
- 🟠 **>** - زيادة السرعة

### أنظمة اللعب
- نظام كومبو (Combo) مع مضاعف النقاط
- شريط سلاح خاص يُشحن بتدمير الأعداء
- 5 مستويات أسلحة مختلفة
- نظام حياة مع فترة مناعة بعد الإصابة

## 🕹️ التحكم

| المفتاح | الوظيفة |
|---------|---------|
| ↑ ↓ ← → أو WASD | تحريك الطائرة |
| SPACE | إطلاق النار |

## 🛠️ التقنيات المستخدمة

- **HTML5 Canvas** - للرسومات والتحريك
- **JavaScript (ES6+)** - منطق اللعبة
- **CSS3** - واجهة المستخدم مع تأثيرات متقدمة
- **RequestAnimationFrame** - حلقة اللعبة بـ 60 إطار/ثانية

## 📐 البنية البرمجية (Architecture)

اللعبة مبنية بنمط **Object-Oriented Programming (OOP)** مع:

- **Game Class:** المتحكم الرئيسي - يدير حالة اللعبة وحلقة التحديث والرسم
- **Player Class:** إدارة الطائرة، الحركة، والإطلاق
- **Enemy Class:** الأعداء مع أنماط حركة وهجوم مختلفة
- **Boss Class:** نظام بوسز متقدم مع مراحل ومناطق هجوم
- **ParticleSystem:** نظام جسيمات مرن للتأثيرات البصرية
- **PowerUpManager:** إدارة التحسينات وتطبيقها

### Design Patterns المستخدمة:
- **State Pattern:** لإدارة حالات اللعبة (Menu, Playing, Paused, GameOver)
- **Factory Pattern:** لإنشاء الأعداء حسب النوع
- **Observer Pattern:** لنظام الأحداث (إصابة، تدمير، جمع)
- **Object Pool:** لإدارة الرصاص والجسيمات بكفاءة
